Log viewer: check a proposal log

This page checks a test log from the CIP prototype: who proposed what, how many people signed, where each proposal is in its comment period, and whether anything in the record was changed. It follows the written rules in prototype/SPEC.md (draft v0.1).

Research prototype on test data. Not a voting system, and CIP is not live. Everything happens in your browser: the page makes no network requests and stores nothing, and the file you choose never leaves your device.

This browser cannot check Ed25519 signatures, so this page cannot verify a log. Use a recent version of Chrome, Firefox or Safari, or run the Node or Python verifier from the prototype folder.

Choose a log

An example loads and is checked straight away. The last two use the same log: on its own it passes every check, and it fails only against a checkpoint that someone saved earlier. That is why the prototype asks people to keep checkpoints.

Files up to 5 MB. A saved checkpoint is one you kept from an earlier time; it lets the page see changes to the part of the log it covers.

Pick an example or choose a file, then check it.

Illustrative prototype. Identities in these logs are test labels that anyone can recompute, and a signature here does not show that a real, unique person signed. The rules, the signature threshold and the comment period are placeholders from the paper's examples (section 4.4.1) and may change. Entry numbers start at 0, as in the spec.
