# Citizens Internet Portal (CIP)

A proposed open-source platform for transparent democratic participation, designed so that capturing it is structurally impractical.

- Overview: https://bettertobest.github.io/portal/
- Research paper: https://bettertobest.github.io/research-hub/citizens-internet-portal.html
- Try it: simulators for [one person one vote vs quadratic voting](https://bettertobest.github.io/portal/simulator/), [liquid delegation](https://bettertobest.github.io/portal/simulator/liquid/), [ranked-choice tie-breaks](https://bettertobest.github.io/portal/simulator/ranked/), and [ledger fork and halt power](https://bettertobest.github.io/portal/simulator/fork/)
- Draft rules: [docs](docs/) (voting rules, ranked choice, halt power, data collection, threat model, milestone plan, Phase 3 prototype plan, test plan, keeping checkpoints, key handling, pilot design, identity linking, advisory notice)
- Prototype (early, test data only): [prototype](prototype/) has a tamper-evident log for proposals and signatures, with two verifiers and deliberately corrupted test logs; the [log viewer](https://bettertobest.github.io/portal/prototype/viewer/) checks a log in your browser
- Contribute: see [CONTRIBUTING.md](CONTRIBUTING.md)
- Talk to us: [Discussions](https://github.com/BetterToBest/portal/discussions)

CIP is the democratic layer of the Compassionism Framework (CCO, PTF, PTH, SZH). This is a research proposal, not a live voting system.
